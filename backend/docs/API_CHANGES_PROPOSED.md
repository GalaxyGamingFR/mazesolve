# API changes proposed

The frontend (or anyone else) proposes contract changes here. The backend lead answers each entry
(accepted / rewritten / rejected), then updates `API.md`, its Changelog and the fixtures together.

## Template

```
### <short title>
- Proposed by: <name>, <date>
- Endpoint / type: <METHOD /path or type name>
- Current: <what API.md says now>
- Wanted: <exact JSON shape or behaviour>
- Why: <what the UI needs it for>
- Status: open | accepted | rewritten | rejected  (backend lead fills in)
```
